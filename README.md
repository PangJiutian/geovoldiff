## 🌍 Overview

**GeoVolDiff** aims to simplify complex geological modeling workflows while expanding the range of structures and conditions it can represent. Designed as a **training data generator for geophysics**, it produces controllable 3D geological volumes for downstream pretraining. We have demonstrated the effectiveness of the generated data in seismic inversion.

> **Actively evolving.** Model weights, conditioning inputs and generation examples will continue to be updated. See our [paper](https://arxiv.org/abs/2606.03572) for the current work; the next version is being prepared.

<a id="getting-started"></a>

## ⚡ Getting Started

```bash
git clone https://github.com/PangJiutian/geovoldiff.git
cd geovoldiff
pip install -r requirements.txt
```

A CUDA-capable GPU is recommended. Model weights and test data: [🤗 PangJiutian/geovoldiff](https://huggingface.co/PangJiutian/geovoldiff).

Place downloaded weights under `train_ckpt/`, set the model and label paths in **[generate_data.ipynb](generate_data.ipynb)**, and run the cells in order. The notebook covers configuration, data formats and visualization.
